FormatScope

Binary format workbench — infer the structure of unknown files, generate a parser, and prove it with a byte-for-byte round-trip.

View on GitHub

Features

  • Drop any binary file — nothing leaves your browser
  • Entropy map + field tree visualization
  • Inference rules: magic, strings, periodicity, TLV, length-prefix, checksums
  • PE, ELF, ZIP, PDF, PNG, JPEG, GIF, BMP, WAV, MP3, SQLite detection
  • x86 opcode, UUID, timestamp, and IP address scanning
  • Generated TypeScript parser with node→line mapping
  • Byte-for-byte round-trip verification
  • Semantic diff between file versions
  • CLI: formatscope inspect, infer, emit, verify, scan
